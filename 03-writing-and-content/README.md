## 核心特性：`human-writing`

- **适用场景**：知乎回答、论坛长帖、公众号文章、博客、人物故事、行业解读、科普评测、口播稿与演讲稿等中文非虚构或虚构内容。
- **核心原则**：不靠堆砌口头禅或网络梗制造“伪活人感”，而是先审查**材料是否充足**、再定**说话位置**、最后打磨**语言节奏**，去除机构腔、营销腔、演说腔与模型排比套路。
- **反凑字数门槛**：非虚构长文若不足五件具体可核验材料，禁止强行扩写凑篇幅，必须先检索补材料、向用户追问或主动缩题短答。
- **明确边界**：不用于公文、合同、技术文档、代码、翻译和列表式短回复。
